LESSON 35 / CSS / 応用

メディアクエリ

画面幅などの条件に応じてCSSを切り替えます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.layout {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 16px;
}
@media (max-width: 500px) {
  .layout { grid-template-columns: 1fr; }
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

@media
表示環境の条件によってCSSを適用。
ブレークポイント
レイアウトを切り替える境界。
レスポンシブ
異なる画面サイズへ適応する設計。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
