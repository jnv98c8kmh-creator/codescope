折り返しとflex値

flex-wrapとflexプロパティで、画面幅に応じて項目を折り返します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.row { display: flex; flex-wrap: wrap; gap: 12px; }
.item {
  flex: 1 1 140px;
  padding: 24px;
  text-align: center;
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

flex-wrap
項目の折り返しを許可。
flex-basis
項目の基準サイズ。
flex-grow
余白を広げる割合。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
