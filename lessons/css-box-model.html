LESSON 25 / CSS / 入門

ボックスモデル

content、padding、border、marginが要素の大きさと間隔を作ります。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.box {
  width: 240px;
  padding: 24px;
  border: 8px solid #4057f2;
  margin: 30px;
  background: #94eee7;
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

padding
枠線の内側の余白。
border
要素を囲む枠線。
margin
枠線の外側の余白。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
