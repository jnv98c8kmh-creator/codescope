選択肢と複数行入力

selectとoptionで選択欄、textareaで複数行の文章入力を作ります。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<label for="course">コース</label>
<select id="course">
  <option>HTML</option>
  <option>CSS</option>
  <option>JavaScript</option>
</select>
<p><label for="message">質問</label></p>
<textarea id="message" rows="4" cols="30"
  placeholder="質問を書いてください"></textarea>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

select
選択肢から一つを選ぶ部品。
option
select内の各選択肢。
textarea
複数行の入力欄。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
