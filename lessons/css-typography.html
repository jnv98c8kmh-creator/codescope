LESSON 33 / CSS / 基礎

文字と読みやすさ

font-family、font-size、line-height、letter-spacingで文章の印象と可読性を整えます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.text {
  max-width: 34em;
  font-family: Georgia, serif;
  font-size: 18px;
  line-height: 1.9;
  letter-spacing: 0.02em;
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

font-family
使用する書体と代替候補。
line-height
行の高さ。
letter-spacing
文字同士の間隔。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
