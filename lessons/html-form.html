フォームの基本

form、label、input、buttonでユーザー入力を受け取る画面を作ります。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<form>
  <p>
    <label for="name">名前</label><br>
    <input id="name" name="name" type="text" required>
  </p>
  <button type="submit">送信する</button>
</form>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

form
入力内容をまとめて送信する領域。
label
入力欄の目的を示すラベル。
required
入力を必須にする属性。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

labelのforと入力欄のidを同じ値にすると、ラベルと入力欄が関連付きます。
