aspect-ratio・object-fit・container

現代的なレイアウトで便利な比率、画像の収まり方、コンテナクエリの入口を学びます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.media {
  width: min(100%, 500px);
  aspect-ratio: 16 / 9;
}
.media img {
  width: 100%; height: 100%;
  object-fit: cover;
  border-radius: 16px;
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

aspect-ratio
要素の縦横比を指定。
object-fit
画像や動画を枠へどう収めるか指定。
コンテナクエリ
親要素の幅を基準にスタイルを切り替える機能。
POINT

Flexbox、Grid、clamp、カスタムプロパティは現在のWeb制作で特に使用頻度が高い機能です。
