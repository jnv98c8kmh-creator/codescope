map・filter・find

配列を変換、絞り込み、検索する代表的なメソッドです。

コードを編集して試す →

SAMPLE CODE

サンプルコード

const scores = [45, 82, 91, 68, 76];
const passed = scores.filter((score) => score >= 70);
const labels = passed.map((score) => "合格: " + score);
const excellent = scores.find((score) => score >= 90);

document.querySelector("#output").textContent =
  labels.join(" / ") + "\n最初の90点以上: " + excellent;

SYNTAX

構文の読み方

命令(引数)

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

map()
各要素を変換した新しい配列を作る。
filter()
条件を満たす要素だけの配列を作る。
find()
条件を満たす最初の要素を返す。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。
