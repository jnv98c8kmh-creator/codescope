関数の定義と呼び出し

処理へ名前を付け、引数を受け取り、戻り値を返します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

function calculateTotal(price, count) {
  const total = price * count;
  return total;
}

const answer = calculateTotal(850, 3);
document.querySelector("#output").textContent =
  "合計 " + answer + "円";

SYNTAX

構文の読み方

命令(引数)

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

関数
再利用できる処理のまとまり。
引数
関数へ渡す値。
戻り値
returnで関数の外へ返す値。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。
