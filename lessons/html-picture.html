レスポンシブ画像

picture、source、srcsetで画面条件に応じた画像を選択します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<picture>
  <source media="(max-width: 500px)"
    srcset="https://picsum.photos/300/300">
  <img src="https://picsum.photos/600/260"
    alt="画面幅で比率が変わるサンプル画像"
    style="max-width:100%;height:auto">
</picture>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

picture
画像候補をまとめる要素。
srcset
表示候補となる画像の一覧。
media
候補を使う画面条件。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
