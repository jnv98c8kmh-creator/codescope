ALL 61 LESSONS

初心者向け
Web制作講座一覧

HTML・CSS・JavaScriptを基礎から順番に学べます。各講座にはコード、構文解説、重要語、注意点があります。

HTML

HTML講座

  1. 文書構造 / 入門HTML文書の基本構造

    Webページを成立させる宣言、html、head、bodyの役割を学びます。

  2. テキスト / 入門見出しと段落

    h1〜h6で文章の階層を作り、pで段落を表します。

  3. テキスト / 入門強調・改行・引用

    strong、em、br、blockquoteなど文章へ意味を追加する要素を学びます。

  4. リンク / 入門リンクとURL

    a要素とhref属性で、別ページやページ内の場所を結びます。

  5. メディア / 入門画像と代替テキスト

    img要素で画像を表示し、alt属性で画像の意味を文章として伝えます。

  6. 文書構造 / 入門箇条書きと番号付きリスト

    ul、ol、liを使い、並列項目や手順を正しく表現します。

  7. セマンティクス / 基礎意味のあるページ構造

    header、nav、main、section、article、footerで領域の役割を示します。

  8. グループ化 / 基礎divとspanの使い分け

    意味を持つ専用タグがないときに、範囲をまとめる汎用要素です。

  9. データ / 基礎表形式のデータ

    table、tr、th、tdで行と列の関係を持つデータを表します。

  10. フォーム / 基礎フォームの基本

    form、label、input、buttonでユーザー入力を受け取る画面を作ります。

  11. フォーム / 基礎入力欄の種類

    type属性を変えると、メール、数値、日付、色などに適した入力UIになります。

  12. フォーム / 基礎選択肢と複数行入力

    selectとoptionで選択欄、textareaで複数行の文章入力を作ります。

  13. インタラクション / 基礎開閉できる詳細情報

    detailsとsummaryだけで、JavaScriptなしの開閉UIを作れます。

  14. メディア / 基礎音声と動画

    audioとvideoでメディアを埋め込み、controls属性で操作UIを表示します。

  15. メディア / 応用レスポンシブ画像

    picture、source、srcsetで画面条件に応じた画像を選択します。

  16. head / 応用meta情報とSEO

    文字コード、画面幅、説明文など、ページ自体の情報をhead内へ記述します。

  17. アクセシビリティ / 応用アクセシブルなHTML

    キーボード操作、ラベル、代替テキスト、自然な要素選択を意識します。

  18. 属性 / 応用data属性

    data-*属性に、JavaScriptから使う独自データを安全に保存できます。

  19. テキスト / 応用特殊文字と文字参照

    タグと解釈される記号や、直接書きにくい文字を文字参照で表します。

  20. 品質 / 応用正しい構造と検証

    タグの入れ子、重複しないid、適切な親子関係を守ることが安定したページにつながります。

CSS

CSS講座

  1. 基本 / 入門CSSの基本構文

    セレクタ、プロパティ、値で「どの要素をどう変えるか」を指定します.

  2. 基本 / 入門さまざまなセレクタ

    タグ、class、id、子孫関係を使って適用先を絞ります。

  3. 見た目 / 入門色と背景

    HEX、rgb、hslなどの色指定と背景色を学びます。

  4. サイズ / 入門CSSの単位

    px、%、em、rem、vw、vhなど、用途に応じた単位を使います。

  5. レイアウト / 入門ボックスモデル

    content、padding、border、marginが要素の大きさと間隔を作ります。

  6. レイアウト / 基礎box-sizingと幅

    border-boxを使うとpaddingとborderをwidthの内側に含められます。

  7. レイアウト / 基礎displayの種類

    block、inline、inline-block、noneによる配置と表示の違いを学びます。

  8. レイアウト / 基礎positionと配置

    relative、absolute、fixed、stickyで通常の流れとは異なる配置を行います。

  9. Flexbox / 基礎Flexboxの基本

    一次元方向の並び、整列、間隔を柔軟に制御します。

  10. Flexbox / 基礎折り返しとflex値

    flex-wrapとflexプロパティで、画面幅に応じて項目を折り返します。

  11. Grid / 基礎CSS Gridの基本

    行と列を持つ二次元レイアウトを作ります。

  12. Grid / 応用自動配置とminmax

    auto-fitとminmaxで、画面幅に応じて列数が変わるカード一覧を作ります。

  13. 文字 / 基礎文字と読みやすさ

    font-family、font-size、line-height、letter-spacingで文章の印象と可読性を整えます。

  14. セレクタ / 基礎疑似クラスと疑似要素

    hoverやfocusで状態を、beforeやafterで仮想的な要素を選びます。

  15. レスポンシブ / 応用メディアクエリ

    画面幅などの条件に応じてCSSを切り替えます。

  16. サイズ / 応用clamp・min・max

    CSS関数で、最小値と最大値を持つ流動的なサイズを作ります。

  17. 設計 / 応用カスタムプロパティ

    色や余白を変数として定義し、再利用と一括変更をしやすくします。

  18. 動き / 応用transformとtransition

    要素を移動・拡大・回転し、状態変化を滑らかにつなぎます。

  19. 動き / 応用キーフレームアニメーション

    @keyframesで時間経過に沿った複数段階の変化を定義します。

  20. 現代CSS / 応用aspect-ratio・object-fit・container

    現代的なレイアウトで便利な比率、画像の収まり方、コンテナクエリの入口を学びます。

JavaScript

JavaScript講座

  1. 基本 / 入門JavaScriptを実行する

    命令を上から順に実行し、console.logで値を確認します。

  2. 基本 / 入門変数 const と let

    値へ名前を付け、再利用します。constは再代入不可、letは再代入可能です。

  3. 基本 / 入門データ型

    文字列、数値、真偽値、null、undefinedなど値の種類を学びます。

  4. 基本 / 入門演算子

    計算、比較、論理演算を行う記号を学びます。

  5. 基本 / 入門テンプレートリテラル

    バッククォートと${}で文字列へ値を読みやすく埋め込みます。

  6. 制御構文 / 入門ifによる条件分岐

    条件がtrueかfalseかによって実行する処理を切り替えます。

  7. 制御構文 / 入門forループ

    同じ種類の処理を指定回数繰り返します。

  8. 関数 / 基礎関数の定義と呼び出し

    処理へ名前を付け、引数を受け取り、戻り値を返します。

  9. 関数 / 基礎アロー関数

    =>を使った短い関数記法とコールバックを学びます。

  10. データ / 基礎配列

    複数の値を順序付きでまとめ、番号やメソッドで操作します。

  11. データ / 基礎map・filter・find

    配列を変換、絞り込み、検索する代表的なメソッドです。

  12. データ / 基礎オブジェクト

    関連する値をキーと値の組でまとめます。

  13. データ / 基礎分割代入とスプレッド構文

    配列やオブジェクトから値を取り出し、コピーや結合を簡潔に書きます。

  14. DOM / 基礎DOM要素を取得する

    querySelectorとquerySelectorAllでHTML要素をJavaScriptから選択します。

  15. DOM / 基礎内容・属性・classの変更

    textContent、setAttribute、classListで表示や状態を変更します。

  16. イベント / 基礎クリックイベント

    addEventListenerでユーザー操作が起きたときの処理を登録します。

  17. イベント / 応用フォーム入力を扱う

    submitイベント、preventDefault、valueを使って入力値を処理します。

  18. Web API / 応用localStorage

    文字列データをブラウザへ保存し、ページをまたいで利用します。

  19. 非同期 / 応用Promiseとasync/await

    時間のかかる処理を待ちながら、読みやすい順序で記述します。

  20. 非同期 / 応用fetchとAPI

    HTTPリクエストで外部データを取得する基本形を学びます。

  21. 設計 / 応用モジュールとコード設計

    exportとimportで機能をファイルへ分割し、責務を整理します。
