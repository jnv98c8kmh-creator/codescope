LESSON 20 / HTML / 応用

正しい構造と検証

タグの入れ子、重複しないid、適切な親子関係を守ることが安定したページにつながります。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<main>
  <section aria-labelledby="lesson-title">
    <h1 id="lesson-title">正しい構造</h1>
    <ul>
      <li>タグを正しく閉じる</li>
      <li>idはページ内で一意にする</li>
      <li>要素の親子関係を守る</li>
    </ul>
  </section>
</main>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

バリデーション
文法や構造が規則に合うか確認すること。
入れ子
要素の中へ別の要素を配置する構造。
一意
同じ範囲に一つしかないこと。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。

広告

学習内容の区切りにのみ広告を掲載します
