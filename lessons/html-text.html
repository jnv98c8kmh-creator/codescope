強調・改行・引用

strong、em、br、blockquoteなど文章へ意味を追加する要素を学びます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<p><strong>重要:</strong> 毎日少しずつ続けましょう。</p>
<p>コードを読み、<br>自分で変更します。</p>
<blockquote>
  <em>作ること</em>が一番の近道です。
</blockquote>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

strong
重要性を表す要素。
em
文脈上の強調を表す要素。
blockquote
まとまった引用を表す要素。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
