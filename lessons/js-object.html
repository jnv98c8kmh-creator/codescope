オブジェクト

関連する値をキーと値の組でまとめます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

const student = {
  name: "Rin",
  level: 3,
  skills: ["HTML", "CSS"]
};

student.level += 1;
document.querySelector("#output").textContent =
  `${student.name} / Level ${student.level}
Skills: ${student.skills.join(", ")}`;

編集したコードが、このプレビュー領域の表示や動作へ反映されます。
