内容・属性・classの変更

textContent、setAttribute、classListで表示や状態を変更します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

const card = document.querySelector(".card");
const title = card.querySelector("h2");

title.textContent = "JavaScriptで変更";
card.setAttribute("data-status", "active");
card.classList.add("accent-card");

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

命令(引数)

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

setAttribute()
属性を設定するメソッド。
classList
classを操作するためのオブジェクト。
add()
classなどへ値を追加するメソッド。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
