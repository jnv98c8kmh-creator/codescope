ifによる条件分岐

条件がtrueかfalseかによって実行する処理を切り替えます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

const score = 78;
let result;

if (score >= 80) {
  result = "合格です";
} else {
  result = "あと少しです";
}

document.querySelector("#output").textContent = result;

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

WORDS

重要語

if
条件が真のとき処理を実行。
else
条件が偽のとき処理を実行。
条件式
trueまたはfalseとして評価される式。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。
