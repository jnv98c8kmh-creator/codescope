LESSON 07 / HTML / 基礎

意味のあるページ構造

header、nav、main、section、article、footerで領域の役割を示します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<header><strong>My Magazine</strong></header>
<nav><a href="#article">記事へ</a></nav>
<main>
  <article id="article">
    <h1>意味のあるHTML</h1>
    <section>
      <h2>なぜ使う？</h2>
      <p>構造が人と機械の両方に伝わります。</p>
    </section>
  </article>
</main>
<footer>© My Magazine</footer>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

セマンティクス
コードへ意味や役割を持たせる考え方。
main
ページ固有の主要内容。
article
単独でも成立する記事や投稿。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。

広告

学習内容の区切りにのみ広告を掲載します
