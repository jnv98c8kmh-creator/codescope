キーフレームアニメーション

@keyframesで時間経過に沿った複数段階の変化を定義します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.dot {
  width: 70px; height: 70px;
  border-radius: 50%;
  background: #4057f2;
  animation: bounce 1.5s ease-in-out infinite;
}
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(130px) scale(.8); }
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

@keyframes
アニメーションの各時点を定義。
animation
名前・時間・速度・回数などをまとめて指定。
infinite
無限に繰り返す値。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
