色と背景

HEX、rgb、hslなどの色指定と背景色を学びます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

body { background: #f1efe7; }
.card {
  color: rgb(24, 30, 42);
  background-color: hsl(177 72% 76%);
  border: 3px solid #4057f2;
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

HEX
#と16進数で表す色。
RGB
赤・緑・青の強さで表す色。
HSL
色相・彩度・明度で表す色。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
