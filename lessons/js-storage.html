localStorage

文字列データをブラウザへ保存し、ページをまたいで利用します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

const input = document.querySelector("#memo");
const button = document.querySelector("#save");
const output = document.querySelector("#output");

input.value = localStorage.getItem("memo") || "";
button.addEventListener("click", () => {
  localStorage.setItem("memo", input.value);
  output.textContent = "ブラウザに保存しました";
});

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

WORDS

重要語

localStorage
ブラウザへ文字列を永続保存するAPI。
setItem()
キーと値を保存。
getItem()
キーに対応する値を取得。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

機密情報や大容量データの保存には向きません。保存値は文字列です。
