箇条書きと番号付きリスト

ul、ol、liを使い、並列項目や手順を正しく表現します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<h2>買うもの</h2>
<ul>
  <li>ノート</li>
  <li>ペン</li>
</ul>
<h2>学習手順</h2>
<ol>
  <li>コードを読む</li>
  <li>変更する</li>
  <li>結果を見る</li>
</ol>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

ul
順序に意味がないリスト。
ol
順番に意味があるリスト。
li
リスト内の各項目。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
