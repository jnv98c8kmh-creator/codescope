アクセシブルなHTML

キーボード操作、ラベル、代替テキスト、自然な要素選択を意識します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<main>
  <h1>設定</h1>
  <label for="volume">音量</label>
  <input id="volume" type="range" min="0" max="100">
  <button type="button" aria-describedby="help">保存</button>
  <p id="help">現在の設定を保存します。</p>
</main>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

アクセシビリティ
障害や環境によらず利用できる度合い。
aria-describedby
要素と詳しい説明を関連付ける属性。
フォーカス
キーボード操作の対象になっている状態。
POINT

まずはbuttonやinputなど、標準で意味と操作性を持つHTML要素を優先します。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。

広告
