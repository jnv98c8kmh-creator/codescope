HTML文書の基本構造

Webページを成立させる宣言、html、head、bodyの役割を学びます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめてのページ</title>
</head>
<body>
  <h1>Hello, Web!</h1>
  <p>ここが画面に表示されます。</p>
</body>
</html>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<!DOCTYPE html>

HTML5で書かれた文書であることを宣言します。

<head> / <body>

設定情報と画面に見える内容を分けます。

WORDS

重要語

要素
開始タグから終了タグまでのひとまとまり。
属性
lang="ja"のように要素へ追加情報を与えるもの。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。

広告
