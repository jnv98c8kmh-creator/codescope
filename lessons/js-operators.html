演算子

計算、比較、論理演算を行う記号を学びます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

const price = 1200;
const count = 3;
const total = price * count;
const freeShipping = total >= 3000;

document.querySelector("#output").textContent =
  "合計: " + total + "円 / 送料無料: " + freeShipping;

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

命令(引数)

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

算術演算子
+ - * / など計算を行う記号。
比較演算子
===や>=など値を比較する記号。
論理演算子
&&、||、!で条件を組み合わせる記号。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
