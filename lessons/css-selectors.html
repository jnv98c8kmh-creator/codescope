さまざまなセレクタ

タグ、class、id、子孫関係を使って適用先を絞ります。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.card { padding: 20px; background: white; }
.card h2 { color: #4057f2; }
#special { border: 3px solid #ff7358; }
.card > p { line-height: 1.8; }

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

classセレクタ
.名前でclassを選択。
idセレクタ
#名前でidを選択。
子セレクタ
>で直接の子だけを選択。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
