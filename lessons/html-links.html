リンクとURL

a要素とhref属性で、別ページやページ内の場所を結びます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<h2 id="top">リンクの例</h2>
<p><a href="https://developer.mozilla.org/">MDNを開く</a></p>
<p><a href="#note">ページ内の説明へ</a></p>
<div style="height:120px"></div>
<p id="note">リンク先の場所です。 <a href="#top">上へ戻る</a></p>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

href
リンク先のURLを指定する属性。
URL
Web上の場所を表す住所。
フラグメント
#idで同じページ内の場所を示す部分。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

新しいタブを開くtarget="_blank"では、必要に応じてrel="noopener"も指定します。
