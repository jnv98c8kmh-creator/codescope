CSS Gridの基本

行と列を持つ二次元レイアウトを作ります。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}
.item:first-child { grid-column: span 2; }

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

grid-template-columns
列の数と幅を定義。
fr
利用可能な余白の割合。
grid-column
項目が占める列を指定。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
