見出しと段落

h1〜h6で文章の階層を作り、pで段落を表します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<h1>Web制作入門</h1>
<h2>HTMLとは</h2>
<p>HTMLは文章の構造を表す言語です。</p>
<h2>次に学ぶこと</h2>
<p>CSSで見た目を整えます。</p>

見出しは大きさだけでなく、文書内の情報階層として認識されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

見出し
章や節のタイトル。h1が最上位です。
段落
ひとまとまりの文章を表すp要素。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。

広告

学習内容の区切りにのみ広告を掲載します
