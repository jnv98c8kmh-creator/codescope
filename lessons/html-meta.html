meta情報とSEO

文字コード、画面幅、説明文など、ページ自体の情報をhead内へ記述します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
    content="width=device-width, initial-scale=1">
  <meta name="description"
    content="HTMLを視覚的に学べるページ">
  <title>ページタイトル</title>
</head>
<body><h1>検索結果にも伝わる情報</h1></body>
</html>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

viewport
スマートフォンでの表示領域設定。
description
ページ内容の要約。
SEO
検索エンジンから見つけやすくする取り組み。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。

広告
