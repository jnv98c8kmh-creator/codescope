divとspanの使い分け

意味を持つ専用タグがないときに、範囲をまとめる汎用要素です。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<div class="card">
  <h2>プロフィール</h2>
  <p>名前: <span class="accent">CodeScope</span></p>
  <p>役割: 学習サポート</p>
</div>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

div
ブロック範囲をまとめる汎用要素。
span
文章中の小さな範囲をまとめる汎用要素。
class
複数要素へ共通の名前を付ける属性。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
