表形式のデータ

table、tr、th、tdで行と列の関係を持つデータを表します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<table border="1" cellpadding="10">
  <caption>学習時間</caption>
  <thead>
    <tr><th>言語</th><th>時間</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML</td><td>5時間</td></tr>
    <tr><td>CSS</td><td>10時間</td></tr>
  </tbody>
</table>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

th
見出しセル。
td
データセル。
caption
表の題名。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

表はレイアウト目的ではなく、行と列に関係があるデータへ使います。

広告
