画像と代替テキスト

img要素で画像を表示し、alt属性で画像の意味を文章として伝えます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<figure>
  <img
    src="https://picsum.photos/360/180"
    alt="教材用のランダムな風景写真"
    width="360"
    height="180">
  <figcaption>画像と説明文の組み合わせ</figcaption>
</figure>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

alt
画像を見られない場合に内容を伝える代替テキスト。
figure
画像や図表など自己完結した内容。
figcaption
figureの説明文。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

装飾だけの画像はalt=""にし、重要な画像は内容が伝わる説明を付けます。
