Flexboxの基本

一次元方向の並び、整列、間隔を柔軟に制御します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.row {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}
.item { flex: 1; text-align: center; }

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

主軸
flex-directionに沿った並び方向。
justify-content
主軸方向の配置。
align-items
交差軸方向の配置。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
