displayの種類

block、inline、inline-block、noneによる配置と表示の違いを学びます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.block { display: block; background: #94eee7; }
.inline { display: inline; background: #f4d85e; }
.inline-block {
  display: inline-block;
  width: 140px;
  padding: 12px;
  background: #ffb39f;
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

block
前後で改行され、横幅いっぱいに広がる表示。
inline
文章の流れの中に並ぶ表示。
none
要素をレイアウトから消す指定。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
