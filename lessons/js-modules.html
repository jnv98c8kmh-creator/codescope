モジュールとコード設計

exportとimportで機能をファイルへ分割し、責務を整理します。

コードを編集して試す →

SAMPLE CODE

サンプルコード

// math.js
export function add(a, b) {
  return a + b;
}

// app.jsでは次のように読み込みます
// import { add } from "./math.js";
document.querySelector("#output").textContent =
  "2 + 3 = " + add(2, 3);

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

命令(引数)

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

モジュール
独立した機能単位のJavaScriptファイル。
export
他ファイルへ公開する値を指定。
import
別モジュールが公開した値を読み込む構文。
POINT

大きなアプリでは、DOM操作、データ処理、通信など責務ごとに分割すると保守しやすくなります。
