transformとtransition

要素を移動・拡大・回転し、状態変化を滑らかにつなぎます。

コードを編集して試す →

SAMPLE CODE

サンプルコード

.card {
  transition: transform .3s, box-shadow .3s;
}
.card:hover {
  transform: translateY(-10px) rotate(2deg);
  box-shadow: 0 18px 35px #17202a33;
}

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

selector { property: value; }

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

transform
移動・回転・拡大縮小などの変形。
transition
状態間の変化を補間。
translate
要素を現在位置から移動。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
