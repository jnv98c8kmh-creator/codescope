入力欄の種類

type属性を変えると、メール、数値、日付、色などに適した入力UIになります。

コードを編集して試す →

SAMPLE CODE

サンプルコード

<label>メール <input type="email"></label><br><br>
<label>人数 <input type="number" min="1" max="10"></label><br><br>
<label>日付 <input type="date"></label><br><br>
<label>色 <input type="color" value="#4057f2"></label><br><br>
<label><input type="checkbox"> 利用規約に同意</label>

編集したコードが、このプレビュー領域の表示や動作へ反映されます。

SYNTAX

構文の読み方

<要素>

記号と単語の組み合わせには、それぞれ決まった役割があります。

WORDS

重要語

type
入力するデータの種類。
min / max
入力可能な最小値と最大値。
checkbox
オン・オフを選ぶ入力欄。
POINT

まずは完全に暗記せず、何を指定すると何が変化するかを結び付けましょう。

CAUTION

記号の閉じ忘れやスペルミスは、表示されない原因になります。
